# Project Guidelines - HANVI GLOBAL TECH

## Overview
Corporate enterprise website for HANVI GLOBAL TECH PVT LTD built with TanStack Start, React 19, and Tailwind CSS.

## Key Architecture
- Main application component: `src/components/hanvi-site.tsx`
- Routing & Root: `src/routes/__root.tsx` and `src/routes/index.tsx`
- Global styles & design tokens: `src/styles.css`
- Assets & Icons: `src/assets/` and `public/`
